# week01-example/

**This is a worked example, not real data.** It exists so the intern can see
the expected shape of a weekly results bundle before they produce their own.

The numbers below are fabricated. Replace with real measurements when running
the baseline on the target server.

- `meta.json` — host facts and what was being measured
- `events.csv` — per-phase timestamps for a fake single-namespace baseline run
- `host-samples.csv` — 10-second slice of 1 Hz host metrics
- `summary.json` — what `scripts/summarize.py` would have written
